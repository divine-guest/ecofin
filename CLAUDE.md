# ЭкоФин — как устроен проект и как с ним работать

Сайт: https://ecofin26.ru — финансы, налоги и право для ИП, самозанятых
и частных лиц. Владелец — ИП Калайтанова О. А.

Подробная хроника работ и принятых решений: [docs/история-работ.md](docs/история-работ.md).

## Язык

Всё по-русски: ответы, тексты сайта, комментарии в коде, сообщения
коммитов. Английские — только имена в коде.

## Порядок выкатки

```bash
python bump-version.py && node build-seo.mjs && python check.py
```

Затем тесты, затем коммит и `git push origin main`. Ветка **main** —
локальная называется master, но пушить нужно в main, иначе изменения
не уедут. Сервер в Yandex Cloud тянет main сам, раз в пять минут.

Офлайновые тесты (сервер не нужен):

```bash
node tests/rates.mjs && node tests/content.mjs && node tests/freshness.mjs
```

Остальные сюиты из `tests/` бьют по боевому серверу и требуют токена —
см. `tests/run-all.mjs`.

## Где правда

Одно значение живёт в одном месте; всё остальное собирается из него.
Дублировать числа руками нельзя — они разойдутся молча.

| Что | Где |
| --- | --- |
| Ставки, лимиты, формулы расчётов | `js/rates.js` |
| Тарифы и цены | `worker/src/plans.js` |
| Статьи базы знаний | `js/knowledge.js` |
| Шаблоны документов | `js/templates.js` |
| Описания страниц калькуляторов | `calc-pages.mjs` |
| Метки «для бизнеса / для себя» | `audience.mjs` |
| Контакты и реквизиты | `js/contacts.js` |

`build-seo.mjs` собирает из этого: страницы статей `st/`, страницы
калькуляторов `calc/`, страницы документов `doc/`, витрины
`dlya-biznesa.html` и `dlya-fizlic.html`, карточки тарифов на главной,
разметку FAQ и `sitemap.xml`. Собранные файлы правит только сборка —
руками в них писать бесполезно.

## Ловушки этой машины

- `bump-version.py` сохраняет HTML в текстовом режиме, поэтому в файлах
  **CRLF**. Скрипты правок обязаны конвертировать образцы поиска.
- Heredoc в Git Bash спотыкается на кавычках — писать файлы через Write,
  а не через `cat <<EOF`.
- `node -e` съедает экранирование: сложные замены — отдельным файлом.
- `curl` к своему домену с машины владельца не проходит. Проверять
  снаружи: `api.hackertarget.com/httpheaders/?q=...` (заголовки) или
  `api.allorigins.win/raw?url=...` (содержимое).
- `worker/node/server-setup/nginx.conf` из репозитория на сервер НЕ
  доезжает: после выпуска сертификата файл под certbot. Живую настройку
  менять только точечной правкой в `setup.sh` с `nginx -t` и откатом.
- Локальная база `worker/data/` в репозиторий не кладётся (в .gitignore).

## Проверять после каждой правки вёрстки

Обе версии: компьютер и телефон. Телефон — главный экран. В браузере
удобно: `preview_start` на `.claude/launch.json`, затем `resize_window`.

## Правила, которые не обсуждаются

- **Персональные данные.** Трансграничная передача заявлена только в
  Китай и только для языковой модели. Telegram выключен (`TELEGRAM_OFF=1`):
  ОАЭ нет в перечне № 128. Регистрация — только по российской почте
  (`ruEmail` в `worker/src/lib.js`).
- **Числа в текстах** считаются функциями из `js/rates.js`, не пишутся
  руками.
- **Обещания на витрине держит код.** Написано «цена не изменится» —
  значит цена фиксируется при оплате (`users.auto_price`).
- Секреты — на сервере в `/opt/pravofin/env` и в метаданных машины
  (`extra-env`), в репозитории их нет.
