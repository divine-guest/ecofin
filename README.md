# ПравоФин

Сервис юридической и финансовой грамотности: ИИ-консультант, разбор документов,
налоговые калькуляторы, курсы и база знаний.

- **Сайт:** https://divine-guest.github.io/ecofin/ (GitHub Pages, ветка `main`)
- **API:** https://pravofin-api.pravofin.workers.dev (Cloudflare Workers + D1)

## Как это устроено

Фронтенд — статические страницы без сборки. Вся логика доступа живёт на сервере:

| Что | Где решается |
|---|---|
| Аккаунты, пароли, сессии | воркер + база D1 |
| Подписка Pro и её срок | воркер |
| Лимиты бесплатного тарифа | воркер, до обращения к ИИ |
| Права администратора | воркер, по списку `OWNER_EMAILS` |
| Ключ ИИ-провайдера | секрет воркера, в репозиторий не попадает |

Браузер только рисует интерфейс. Правка `localStorage` меняет картинку,
но не даёт ни подписки, ни админки — сервер проверяет всё заново.

## Роли

- **owner** — задаётся переменной `OWNER_EMAILS`. Может выдавать и снимать
  права администратора через админ-панель.
- **admin** — видит пользователей и выручку, выдаёт подписки. Раздавать
  админку не может.
- **user** — обычный пользователь.

## Развёртывание API

```bash
cd worker
cp .env.example .env      # заполнить значения
CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... node deploy.mjs
```

Скрипт сам создаёт базу, применяет `schema.sql`, заливает переменные,
секреты и код. Wrangler не нужен. Если права на Workers и на D1 лежат
в разных токенах, второй передаётся в `D1_API_TOKEN`.

Проверка: `curl https://pravofin-api.pravofin.workers.dev/api/health`

## Перед коммитом фронтенда

```bash
python bump-version.py
```

Проставляет номер версии всем css/js: `js/app.js?v=5`. Без этого вернувшийся
посетитель получает новый HTML и старый JS из кэша браузера (GitHub Pages
отдаёт файлы с `max-age=600`) — и сайт падает на вызовах функций, которых
в старом файле ещё нет. Тот же номер уходит в имя кэша service worker.

## Ставки и лимиты

Все суммы, ставки и пороги, которые меняет законодатель, собраны
в [`js/rates.js`](js/rates.js) — с датой последней сверки. Меняется норма —
правится одна строка, а не пять калькуляторов. **Сверяйте перед каждым
новым годом** по НК РФ и сайту ФНС.
