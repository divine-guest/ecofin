# Домен сайта. Одна строка, без http:// и без косой черты в конце.
#
# Как только сюда впишут имя и оно начнёт показывать на адрес машины,
# сервер сам выпустит сертификат Let's Encrypt и включит HTTPS — проверка
# идёт каждые пять минут, заходить на сервер не нужно.
#
# Домен не секрет, поэтому лежит прямо в репозитории: вписать, закоммитить,
# отправить — и через несколько минут сайт откроется по https.
#
# ---------------------------------------------------------------------
# Домен куплен и вписан. Временное имя 84-201-164-112.nip.io больше
# не используется — чистить его нигде не нужно, оно просто перестанет
# открываться, когда о нём забудут.
#
# Как это было устроено до покупки:
#
# nip.io — служба, которая любому имени вида 84-201-164-112.nip.io
# отвечает тем самым адресом, что зашит в имени. Своего домена у нас пока
# нет, а HTTPS нужен уже сейчас, и вот почему:
#
#   • Telegram принимает вебхук только по https. Без него бот остаётся
#     на старом сервере и пишет в старую базу — данные разъедутся.
#   • Оплата и пароли по незащищённому соединению — недопустимо.
#   • Браузер не даёт странице с https обращаться к серверу по http,
#     из-за чего сайт на GitHub Pages не может пользоваться новым API.
#
# Домен куплен и вписан ниже. Сервер проверяет раз в пять минут, показывает
# ли он на нас, и как только показывает — сам выпускает сертификат.
#
# Временное имя 84-201-164-112.nip.io больше не нужно и нигде не чистится:
# оно просто перестанет использоваться. В списке разрешённых адресов
# (env-public.txt) его пока оставили — пока домен расходится по DNS, часть
# людей ещё приходит по старому адресу.
#
# ---------------------------------------------------------------------
# ПЕРВАЯ строка — основной домен, на нём живёт сайт.
# СЛЕДУЮЩИЕ — зеркала: они переадресуются на основной насовсем (301).
#
# Зеркало нужно, потому что по-русски пишут и «eco», и «eko»: половина
# людей наберёт не ту букву. Но жить сайт должен по одному адресу —
# иначе поисковик видит два одинаковых сайта и делит вес между ними,
# а люди пересылают друг другу разные ссылки на одно и то же.
#
# Сертификат выпускается на все имена сразу, включая www. Имя, которое
# ещё не показывает на сервер, пропускается и подхватится при следующей
# проверке — так один неверно настроенный псевдоним не оставит без https
# основной домен.
