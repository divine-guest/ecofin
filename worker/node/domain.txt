# Домен сайта. Одна строка, без http:// и без косой черты в конце.
#
# Пока файл пустой, сервер работает по обычному HTTP на IP-адресе.
# Как только сюда впишут домен и он начнёт показывать на адрес машины,
# сервер сам выпустит сертификат Let's Encrypt и включит HTTPS —
# проверка идёт каждые пять минут, заходить на сервер не нужно.
#
# Домен не секрет, поэтому лежит прямо в репозитории: вписать, закоммитить,
# отправить — и через несколько минут сайт откроется по https.
#
