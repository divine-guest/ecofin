# Настройки, которые не секрет.
#
# Секреты — ключи, токены, пароли — живут только на самой машине, в файле
# /opt/pravofin/env, и в репозиторий не попадают никогда. Но не всё в
# настройках секретно: адрес сайта знает каждый посетитель, список
# разрешённых источников — тоже не тайна.
#
# Такие строки лежат здесь. Установщик накладывает их поверх машинных:
# что написано тут, то и побеждает. Значит поменять адрес сайта можно
# обычной выкладкой, не пересоздавая машину и не трогая секреты.
#
# Формат обычный: КЛЮЧ=значение, по одной строке. Пустые строки и строки,
# начинающиеся с решётки, пропускаются.
#
# ВАЖНО: сюда нельзя класть ключи и токены. Репозиторий открыт, и всё,
# что здесь написано, видно всему интернету.

# Остановка передачи за пределы страны
#
# Уведомление о трансграничной передаче по части 4 статьи 12 152-ФЗ
# подаётся ДО начала передачи. Пока оно не подано, единственный честный
# способ ничего не нарушать — не передавать.
#
# Раскомментировать строку, отправить в репозиторий — через несколько
# минут сервер подхватит и направление закроется. Заходить на машину не
# нужно, код не трогается, ключи остаются на месте.
#
# Что при этом происходит:
#   AI_ABROAD_OFF=1  — ИИ-консультант и разбор документов отвечают
#                      понятным «временно отключено, вот почему», а не
#                      служебной ошибкой. Распознавание фотографий
#                      продолжает работать: оно идёт внутри страны.
#   TELEGRAM_OFF=1   — бот не отвечает и не рассылает, входящие
#                      сообщения не разбираются. Напоминания продолжают
#                      приходить на сайте.
#
# Всё остальное — расчёты, документы, учёт, база знаний — работает.
#
# Передача за границу остановлена 09.09.2026.
#
# Уведомление о трансграничной передаче подаётся ДО начала передачи
# (ч. 3 ст. 12 152-ФЗ), а передача идёт с конца августа. Пока
# уведомление не подано, единственный честный способ ничего не
# нарушать — не передавать.
#
# Пауза не стирает прошлый период, но прекращает длящееся нарушение:
# с этого дня начинает течь срок давности, и добровольное прекращение
# противоправного поведения работает как смягчающее обстоятельство
# (ст. 4.2 КоАП).
#
# СНЯТЬ СРАЗУ ПОСЛЕ ПОДАЧИ. Китай в перечне государств приказа
# Роскомнадзора № 128 — туда можно передавать с момента направления
# уведомления, решения ждать не нужно. Закомментировать строку,
# отправить, через пять минут консультант работает.
AI_ABROAD_OFF=1

# Telegram выключен с 08.09.2026.
#
# Причина не в самом боте, а в перечне государств. Вычисления языковой
# модели идут в Китае, а Китай входит в перечень государств,
# обеспечивающих адекватную защиту (приказ Роскомнадзора № 128) — туда
# передавать можно сразу после направления уведомления. Уведомления
# мессенджера идут в ОАЭ, а ОАЭ в перечень не входят, и это переводит
# всю передачу в тяжёлый режим: ждать решения, отдельно обосновывать.
#
# Один канал доставки напоминаний не стоит того, чтобы из-за него
# ждать решения по основной функции сервиса. Напоминания продолжают
# приходить на сайте.
#
# Включать обратно — после того как будет решено, подаётся ли отдельное
# уведомление по ОАЭ. Убрать строку, отправить, через пять минут бот
# снова работает.
TELEGRAM_OFF=1

# Зрячая модель для распознавания снимков

# Порядок распознавания: облачный Vision в России, если задан ключ →

# а причина пишется в журнал.
#
# ЧТО СДЕЛАТЬ ПЕРЕД ТЕМ, КАК РАСКОММЕНТИРОВАТЬ. В панели AITunnel у
# API-ключа стоит список разрешённых моделей — сейчас там deepseek-chat

# gemini-2.5-flash: это США, а США в перечне нет. Тогда ключ физически
# не сможет обратиться туда, чего нет в нашем уведомлении, — защита,
# которая не зависит от кода.
#
# Выбрана 09.09.2026: GLM 4.6V, Zhipu AI, Китай.
#
# Проверена на русском счёте — прочитала номер, ИНН, сумму и фамилию,
# четыре значения из четырёх. Китай в перечне государств приказа
# Роскомнадзора № 128, тот же, что у текстовой модели: в уведомлении
# одна страна, а не две.
#
# На машине в worker/.env оставалось gemini-2.5-flash от прежней
# настройки — это США, и белый список в lib.js её не пропускал.

# ---------------------------------------------------------------------
# Текстовая модель
#
# Выбрана 09.09.2026: DeepSeek V4 Flash. До этого стояла deepseek-chat.
#
# Почему сменили. На проверке из четырёх расчётных вопросов V4 Flash
# дал верный итог обе попытки подряд, GigaChat 2 и 2 Pro ошиблись в
# сумме. При этом V4 Flash в восемь раз дешевле прежней модели
# (2.6 и 32 ₽ за миллион токенов против 51 и 206) и заметно быстрее.
#
# Разрешённые значения — в белом списке TEXT_ALLOWED в worker/src/lib.js:
# только Россия и государства из перечня приказа Роскомнадзора № 128,
# совпадающие с уведомлением о трансграничной передаче. Незнакомое имя
# не подставляется по умолчанию: консультант отвечает, что недоступен,
# и пишет причину в журнал.
#
# Меняете модель — прогоните расчётный вопрос дважды и прочитайте ИТОГ
# глазами. Верные слагаемые при неверной сумме — самая частая ошибка
# моделей, и поиск подстроки её не ловит.
AI_MODEL=deepseek-v4-flash
